# TahaTyper Lite - Chrome Extension Installation Guide 🚀

TahaTyper Lite is a Chrome Extension that works on **Chromebooks**, **Windows**, **macOS**, and **Linux**. It allows you to auto-type into any website like Google Docs, Gmail, school portals, and more!

## Installation Steps

### 1. Download the Extension Files
- Download the `TahaTyper_Chrome_Extension` folder from the GitHub release.
- Extract it to a folder on your computer.

### 2. Open Chrome Extensions Page
1. Open **Google Chrome** (or any Chromium-based browser like Edge, Brave, etc.)
2. Go to: `chrome://extensions/`
3. Or click the **Menu** (three dots) → **More Tools** → **Extensions**

### 3. Enable Developer Mode
- In the top-right corner of the Extensions page, toggle **"Developer mode"** ON.

### 4. Load the Extension
1. Click **"Load unpacked"** button that appears.
2. Navigate to and select the `TahaTyper_Chrome_Extension` folder.
3. Click **"Select Folder"**.

### 5. Done! 🎉
- TahaTyper Lite will now appear in your Chrome extensions.
- Click the **robot icon** in the top-right corner to open TahaTyper Lite.

## How to Use

1. **Enter Text**: Type or paste the text you want to auto-type into the text box.
2. **Adjust Settings**: 
   - Control the typing speed (10-300ms)
   - Toggle randomized delays, punctuation pauses, and mistakes
3. **Choose the destination tab**: Use the **Type only in this tab** list and select your school or Google Docs tab.
4. **Focus the destination field**: Click the text field in the selected tab before opening the extension popup.
5. **Click START**: TahaTyper sends typing commands only to the selected tab and waits 3 seconds before typing.
6. **Work safely elsewhere**: Switch to your work account or another tab. TahaTyper continues only in the selected destination tab and will not transfer typing to the tab you are viewing.
7. **Click STOP**: Stop the typing at any time.

## Troubleshooting

### "Please click into a text field first!"
- Make sure you click into a text input field BEFORE clicking START.
- The extension needs to know where to type!

### Not working on a specific website?
- Some websites have special security restrictions.
- Try refreshing the page and try again.
- Make sure the text field is properly focused (cursor visible).
- If the tab was opened before the extension was installed or reloaded, refresh that tab once so the content script is available.
- Use the refresh button beside the tab list if you opened or closed tabs after opening the popup.

### How do I remove it?
- Go to `chrome://extensions/`
- Find TahaTyper Lite and click the **trash icon**.
